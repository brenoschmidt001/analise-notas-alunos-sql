# 📊 Análise de Notas dos Alunos

## Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas.

O objetivo é utilizar SQL para armazenar as notas dos alunos, calcular suas médias e identificar aqueles que obtiveram média igual ou superior a 7.

## Tecnologias utilizadas

![SQL](https://img.shields.io/badge/SQL-4479A1?style=for-the-badge&logo=mysql&logoColor=white)
![GitHub](https://img.shields.io/badge/GitHub-181717?style=for-the-badge&logo=github&logoColor=white)

## Funcionalidades

- Criação de uma tabela de notas.
- Cadastro de oito alunos.
- Armazenamento de duas notas por aluno.
- Cálculo da média aritmética.
- Consulta dos alunos com média igual ou superior a 7.
- Utilização de CTE (Common Table Expression).

## Como executar

1. Instale o MySQL 8.0 ou superior.
2. Clone este repositório:

```bash
git clone https://github.com/brenoschmidt001/analise-notas-alunos-sql.git
```

3. Abra o MySQL Workbench.
4. Crie um banco de dados vazio e selecione-o.
5. Abra o arquivo `notas.sql`.
6. Execute o código completo.
7. Confira o resultado da consulta.

## Demonstração do resultado esperado

| Aluno | Média |
|-------|-------|
| Ana | 8.50 |
| Mariana | 9.50 |
| Pedro | 7.50 |
| Beatriz | 8.00 |

## Aprendizados

Com este projeto, pratiquei a criação de tabelas, inserção de dados, cálculos e consultas utilizando SQL. Também aprendi a utilizar CTE para organizar melhor as consultas ao banco de dados.
